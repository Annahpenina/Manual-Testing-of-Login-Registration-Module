# Manual-Testing-of-Login-Registration-Module
📌 Project Title
Manual Testing of Login & Registration Module

📝 Project Description
This project demonstrates manual software testing skills applied to a sample Login and Registration module.
It includes requirement analysis, test planning, test case design, test execution, defect reporting, and final test summary report.
The goal of this project is to practice:
    • Software Testing Fundamentals
    • SDLC & STLC concepts
    • Test design techniques
    • Bug life cycle
    • Preparing professional testing documents
This project is based on concepts learned from Guru99 Manual Testing tutorials.

🎯 Objectives of the Project
    • Understand and apply STLC phases
    • Design test scenarios and test cases
    • Perform positive and negative testing
    • Execute test cases and log results
    • Identify defects and write bug reports
    • Prepare a Test Summary Report

🧩 Scope of Testing
Modules covered:
    • User Login
    • User Registration
    • Input Validation
    • Error Messages
    • Logout Functionality
Out of scope:
    • Performance testing
    • Security testing
    • Database testing

🔧 Test Environment
    • Platform: Web Application
    • OS: Windows
    • Browser: Chrome
    • Testing Type: Manual Testing

🧪 Types of Testing Performed
    • Functional Testing
    • UI Testing
    • Boundary Value Analysis
    • Positive & Negative Testing
    • Retesting
    • Regression Testing
